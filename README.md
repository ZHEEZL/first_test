---

## Содержание работы

Проект реализует требования лабораторного практикума по алгоритмам и структурам данных:

1. **Часть I. Функции и алгоритмы обработки вектора**:
   - Постоянная функция $f(v) = 1$ — $O(1)$
   - Сумма элементов вектора — $O(n)$
   - Произведение элементов вектора — $O(n)$
   - Наивное вычисление значения полинома степени $n-1$ в точке $x = 1.5$ — $O(n^2)$
   - Вычисление полинома по схеме Горнера — $O(n)$
   - Сортировка пузырьком (Bubble sort) — $O(n^2)$
   - Быстрая сортировка (Quick sort) — $O(n \log n)$
   - Гибридная сортировка Timsort (естественные прогоны + бинарная вставка + стек слияний) — $O(n \log n)$

2. **Часть II. Матричные вычисления**:
   - Классическое матричное произведение случайных матриц $A \times B$ размера $n \times n$ — $O(n^3)$

3. **Часть III. Индивидуальный нетривиальный алгоритм**:
   - **Сортировка Шелла (Shell Sort)** с классической последовательностью шагов Кнута ($h_{k} = 3h_{k-1} + 1$: $1, 4, 13, 40, 121, 364 \dots$) — теоретическая сложность $O(n^{1.5})$.

4. **Часть IV. Алгоритмы возведения в степень (подсчёт элементарных операций)**:
   - Простой алгоритм (Рис. 1 методички: последовательное умножение) — $O(n)$
   - Рекурсивный алгоритм RecPow (Рис. 2 методички) — $O(\log n)$
   - Быстрый алгоритм QuickPow (Рис. 3 методички: старшие биты вперёд) — $O(\log n)$
   - Классический быстрый алгоритм QuickPow1 (Рис. 4 методички: младшие биты вперёд) — $O(\log n)$
   - *Примечание*: для алгоритмов возведения в степень замеряется не процессорное время, а **точное число элементарных операций (умножений / шагов)**, строятся ступенчатые логарифмические кривые.

## Архитектура и инженерные решения

### 1. Измерительный контур и префиксы данных
- **Базовый вектор $V$**: генерируется один раз в классе `ExperimentContext` с фиксированным seed и **никогда не модифицируется**.
- **Префиксы**: для каждого значения $n$ берется неизменный срез первых $n$ элементов ($n = Step, 2 \cdot Step, \dots, MaxN$). Сортировки клонируют префикс в буфер `Work` вне тайминга замера.
- **Стабилизация CPU и JIT**: метод `GlobalWarmup` прогревает JIT всех методов, структуры данных и выполняет 100 мс спиннинг CPU для перевода ядер Windows в состояние максимального Turbo Boost до старта измерений.
- **Фильтрация выбросов**: метод `RobustMean` использует модифицированную $z$-оценку на базе медианного абсолютного отклонения (MAD) с порогом $3.5 \cdot \text{MAD} / 0.6745$.

### 2. База данных SQLite и умное кэширование
- Модуль `BenchmarkDb.cs` (`benchmark.db`) сохраняет результаты всех индивидуальных повторов с транзакционной группировкой.
- **Кэширование**: если для алгоритма при данном $n$ и количестве повторов данные уже есть в БД, точка подтягивается моментально (время повторного прогона 14 алгоритмов по 40 точек составляет **0.2 секунды** вместо 28 с).
- В интерфейсе предусмотрена опция принудительного перерасчета в обход кэша.

### 3. Оценка точности (MSE)
Для каждого алгоритма вычисляется среднеквадратичная ошибка аппроксимации:
$$MSE = \frac{1}{k} \sum_{i=1}^{k} \left( y_{\text{эмпирическое}}(n_i) - C \cdot f(n_i) \right)^2$$
где коэффициент $C$ находится методом наименьших квадратов (МНК). Ошибка выводится в сводной таблице, заголовках графиков и экспортируемом CSV.

### 4. Вкладка «Сравнение из истории»
- Позволяет выбрать сохранённые сессии экспериментов из базы SQLite.
- Выбрать интересующий алгоритм и построить сравнительный график с наложением кривых разных запусков на одной координатной плоскости.

## Сборка и запуск

### Требования
- [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- ОС Windows 10/11 (для запуска оконного интерфейса WinForms)

### 1. Оконный интерфейс (GUI)
```powershell
dotnet run --project first
```
В интерфейсе доступны:
- Выбор алгоритмов галочками.
- Редактирование $Max N$, шага сетки ($Step$) и количества повторов ($Runs$) прямо в таблице.
- Кнопка сброса параметров к дефолтным значениям.
- Чекбоксы включения/отключения кэша SQLite и глобального прогрева.
- Вкладки с интерактивными графиками ScottPlot.
- Вкладка «Сравнение из истории».
- Экспорт таблицы в CSV и графиков в PNG.

### 2. Консольный режим (без открытия окна)
```powershell
dotnet run --project first -- --no-window
```
Автоматически проводит прогрев, запускает замеры всех 14 алгоритмов, выводит сводную таблицу в консоль, сохраняет результаты в `results.csv`, графики в папку `charts/` и обновляет `benchmark.db`.

### 3. Диагностика влияния холодного старта JIT и CPU
```powershell
dotnet run --project first -- --check-init
```
Демонстрирует разницу между первым «холодным» вызовом метода и прогретым (ускорение до $\times 600..900$ раз).
